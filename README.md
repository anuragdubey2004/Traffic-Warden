Traffic Warden is a Full-Stack Rate Limiting System designed to protect backend APIs from being overwhelmed by too many requests. 
Using a sliding window algorithm powered by Redis (Upstash) and Node.js, it tracks user activity by IP address and automatically blocks access after a set limit is reached. The frontend is built with React and TypeScript to provide a real-time, responsive user experience.
